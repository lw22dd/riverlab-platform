# 都江堰「一江 → 两江」三维复原：外部求解上下文包

> 给外部 AI 的说明：你没有我们的代码库访问权限，也不需要。下面是一个自包含的背景包：我们要做什么、已经有什么、卡在哪、希望你按什么结构回答。所有尺寸单位都是"平面单位"（见 §2），不是米。

## 0. 一句话任务

把一张**现代景区导览图**反演成**公元前 256 年建堰之前**的河势，并用一段可交互的 Three.js 动画演出"玉垒山挡水 → 火烧水激凿开宝瓶口 → 竹笼筑鱼嘴/金刚堤 → 飞沙堰溢流排沙 → 岁修 → 成都平原得水"；最终产物是**一个离线单文件 HTML**，既是教学动画，也是交给 3D 生成 AI 的建模需求书。

现在需要你解决的，是其中三件事：**建成前地形怎么反演**、**低多边形下怎么把因果讲清楚**、**需求书怎么写才可执行**。

## 1. 我们要的两样东西

1. 一段**离线单文件 HTML 动画**（Three.js）：约 60–90 秒可循环，8 个阶段，可暂停、可拖动时间轴、可按阶段跳转；手机竖屏可用。
2. 同一份文件同时是**建模需求书**：每个部件的尺寸、拓扑、材质、实例数、动画挂点、验收视角都能被一个只能看文字和参考图的 3D 生成 AI 直接执行。

## 3. 史实基线（用户给定，视为硬约束）

- **没有人工分叉**：岷江刚出山口时就是一条完整的单股大河，江心里没有鱼嘴和金刚堤。
- **玉垒山彻底挡水**：右侧的山脊（玉垒山）完好无缺，把岷江死死挡住，逼着江水拐弯流走，导致山背后的成都平原（右上角）得不到灌溉，也就是"未解封的天府之国"。
- **金刚堤是依托自然江心洲人工修筑出来的**：不是凭空在江心堆一条堤，而是先有沙洲，再在洲上抛竹笼、加高加宽，把天然洲变成人工分水堤。

文献锚点：《史记·河渠书》"蜀守冰凿离碓，辟沫水之害，穿二江成都之中"；《华阳国志·蜀志》。除明确引文外，人物对白与施工细节都是教学演绎。

### 4.3 数据本身的五个缺陷（也是问题的一部分）

- **D1 地图是"建成后"的**：内江、外江、鱼嘴、金刚堤、飞沙堰、宝瓶口都已经画在图上。"建成前"不能靠隐藏道具得到，必须反演。
- **D2 取水口只被"标注"、没有被"打开"**：山体多边形在宝瓶口处是一个凹口，主水体在喉口两侧各断一次；当前代码只能沿 POI 切一条 2.0 单位宽的走廊，再用一小片水面盖住。
- **D3 河口段被现代设施扭曲**：主环 62–127 号点受导览图栈道/标牌影响，同一纬度会出现 3 段水面（1.1 / 3.4 / 3.0 单位宽），河宽在 5–14 单位之间跳变。
- **D4 无高程、无真实比例**：山 8.6、平原 0.3–0.6、河床 −0.04；宝瓶口两侧地形只有 0.3–1.0，是低鞍部而不是峡谷。
- **D5 江心洲太长**：369 单位² 的长条洞从 Z=+21 延伸到 Z=−42.4，包含现代人字堤与下游洲，比历史上的分水堤长得多。

## 5. 当前实现与已确认的问题

已经做了：山体多边形约束三角化 + 边界距离场生成高程（<30k 三角面）；主水体铺面 + 自定义水 shader（波纹、岸沫、深度色）；内/外江两条 ribbon 做流向；程序化竹笼（instanced 编织）、杩槎（三脚架 + 压石 + 上游席）、火床、飞沙堰竹笼层；火焰、淬冷蒸汽、烟尘、崩岩、落石、水花粒子；17 个 action 串成 8 个阶段。

已知问题（每条都对应后文一个提问）：

- **P1 开场即双汊**：第一帧水面直接铺"建成后"地图，观众看到的已经是分好水的河，与"单股大河"直接矛盾。
- **P2 山挡不住水**：宝瓶口处是 0.3–1.0 的鞍部，8.6 的峰在 10 单位之外；"山脊阻隔"目前靠字幕，不靠画面。
- **P3 岩塞是二值开关**：8 块 box/dodecahedron，凿开瞬间消失；没有"火烧—淬冷—裂—撬—崩"的连续形态变化。
- **P4 江心洲是固定高地**：没有"枯水出露、洪水过流"的沙洲行为，"依托自然洲筑堤"讲不出来。
- **P5 分水靠标签**：内/外江的流量、流速、泡沫线没有可读差异，"四六分水"无法从画面验证。
- **P6 旱/涝是一次透明度渐变**：没有"水到田头"的因果链（宝瓶口 → 干渠 → 支渠 → 田块）。
- **P7 尺度不统一**：若全图按 2–3 km 估，1 单位 ≈ 20–30 m；山高 8.6 单位 ≈ 170–260 m；宝瓶口 2.4 单位 ≈ 50–70 m，比通常记载的约 20 m 宽 2–3 倍。
- **P8 年代风险**：岁修用"卧铁"作深度基准，而卧铁通常认为是明清遗物；秦代是否有同类标记需要核。
- **P9 分支不进画面**：6 次选择里只有"堰高"和"分流"真正改变 3D；鱼嘴用料（石/土/竹笼）、开凿工法（锤凿/绕行）在动画里没有对应形态。

## 6. 请回答的 8 个问题

### Q1（最重要）建成前河势怎么反演

已知：一张建成后的矢量平面 + 两条史实约束。求一套**可复现**的反演方法，而不是再手绘一张示意图（我们已经手绘过一张，见附件 B，它和矢量图不能逐点配准）。

请回答：

1. 单股主槽的**中心线**与**宽度函数**怎么定？用哪几条边界做约束（西岸、东岸、山脚线）？河口段的 3 段碎水面怎么并成一条？
2. 天然江心洲保留几个、放在哪、洲顶高程多少（相对水面），才能既支撑"依洲筑堤"，又不让观众读成"已经分好的两条河"？
3. 玉垒山的**封口线**画在哪里？怎么从现代山体多边形里提取"山脊带"（西侧临江线 + 东侧山脚线）？
4. 反演结果与建成后地图如何**配准**（同一锚点、同一比例）？允许哪些"艺术偏离"，不允许哪些？
5. 判定：什么条件下算"单股"，什么条件下会被读成"两条挨得很近的河"？

期望形态：步骤 + 需要新增的图层 + 参数表 + 一张文字/ASCII 示意。判定标准：我们能照着你写的步骤，在同一份 JSON 上复现出同一张平面。

### Q2 玉垒山与宝瓶口的形态和尺度

现状：山脊峰值 8.6，喉口两侧 0.3–1.0，喉口宽 2.4，山脊带最窄处约 5 单位。

请给出：

1. 山脊的**剖面参数**：顶宽、坡角、相对水面高差、山脊带宽度、沿江延伸长度；哪些地方必须加陡、加高。
2. 宝瓶口的**断面**：宽、深、长、喉口收束形态；"火烧水激"后岩壁应该是什么样（崩落面、裂隙、焦黑、临水面）。
3. **尺度换算**：真实尺寸取多少、模型取多少、垂直夸张系数取多少；在 45° 俯视、100 单位画幅下，什么高差能让"山挡水"在静音无字幕时也成立。
4. 判定：从默认全景机位看，水面是否在视觉上"撞到山脚再拐弯"，而不是"穿过一个缺口"。

### Q3 单股 → 双股怎么演

候选方案（可组合）：

- A. 沙洲抬升：洲顶从水下抬到水面以上，竹笼一层层加上去，水自己分成两股。
- B. 水面连续 + 堤是不透明墙：水面始终是一整片，靠堤体遮挡与流向箭头区分内/外江。
- C. 两张水面交叉淡化：建堤瞬间把单股水面换成内/外两张。

请评判三者在**低多边形 + 固定机位**下的可读性、实现成本、失败模式，推荐一种，并给出逐拍脚本（0–6 秒建堤；枯水与洪水两种分流结果）。另外：**"四六分水"用什么水面证据表达**（流速、泡沫线、水位差、流线密度）？

判定：静音、无字幕、只看 3 秒，观众能说出"河被分开了"。

### Q4 "未解封的天府之国"怎么可视化

开凿前后，平原的差异要一眼可读，且不靠字幕。请给三层尺度（航拍、中景、近景）的具体视觉线索：色彩、几何、材质、动静；以及"水到田头"的因果链动画（宝瓶口 → 干渠 → 支渠 → 田块）。请标明哪些线索是史实、哪些是教学演绎（例如"旱"是否应该表现为龟裂、枯黄、扬尘，还是仅仅没有水渠）。

判定：把开凿前/后两帧并排，非专业观众能指出"哪边有水、哪边没水"。

### Q5 史实校核

请逐条给结论、置信度、依据：

1. 阶段顺序"凿离堆（宝瓶口）→ 筑鱼嘴/金刚堤 → 飞沙堰"是否成立？还是应该交错施工？
2. "火烧水激"是否可信？怎么表现才不误导（火堆位置、水量、裂纹方向、工期）？

4. "深淘滩，低作堰"六字诀与"四六分水"的说法分别出自什么时代？动画里直接引用会不会年代错位？

判定：每条都有置信度；凡"低"置信度，必须给一个安全的替代表现。

## 10. 术语

| 词 | 含义 |
| --- | --- |
| 鱼嘴 | 分水堤的迎水前端，形如鱼吻；把岷江分成内江、外江 |
| 金刚堤 | 鱼嘴之后的分水长堤，本项目设定为"依托自然江心洲人工加筑" |
| 飞沙堰 | 内江侧的低矮溢流堰，洪水时把多余水量与泥沙排回外江 |
| 宝瓶口 | 凿开玉垒山形成的引水口，控制进入成都平原的流量 |
| 离堆 | 宝瓶口凿开后与大山分离的孤堆 |
| 杩槎 | 三脚木架 + 压石 + 上游席，岁修时截断内江 |
| 竹笼 | 竹篾编的长笼，装卵石后层层叠砌成堤、成堰 |
| 卧铁 | 埋于河床的深度基准（本项目怀疑其年代，待核） |
| 四六分水 | 枯水期内江约六成、外江约四成；洪水期相反（待你校核） |
| 岁修 | 每年枯水期的清淤、修堤、换笼 |
